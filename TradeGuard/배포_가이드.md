# 웹 배포 가이드 — Render 무료 플랜

> 심사위원이 **링크 클릭 한 번으로** TradeGuard를 쓸 수 있게 합니다.
> 소요 15분 · 비용 0원 · 신용카드 불필요 · **Docker 불필요**

---

## 왜 Render인가

| 후보 | 판단 |
|---|---|
| **Render 무료** ✅ | Python을 그대로 실행. 카드 불필요. **15분 미사용 시 잠들고 재기동 30~60초** |
| Netlify ❌ | 정적 사이트 + JS/Go 서버리스만. **Python 런타임이 없어 FastAPI를 못 돌립니다** |
| Hugging Face Spaces ❌ | Docker·Gradio Space는 유료 플랜(PRO)이 필요합니다 |
| Vercel ⚠️ | Python은 되지만 **서버리스**라 호출마다 프로세스가 새로 뜹니다. 사용량 카운터가 메모리에 있어 **IP별 상한이 매번 초기화**되고, API 비용 방어가 무너집니다 |

---

## 0. 준비물

- Render 계정 (GitHub 로그인으로 가입, 무료) — https://render.com
- OpenAI 또는 Anthropic API 키 1개
- **판독 접근 코드** — 아무 문자열이나 정하십시오. 예: `KB2026-TRADEGUARD`

> 접근 코드가 **API 비용이 새는 것을 막습니다.** 공개 URL이라 누구나 호출할 수 있어서,
> 코드 없이 열어 두면 하루 만에 크레딧이 빕니다. 코드는 **제출 자료에만** 적습니다.

---

## 1. 배포

저장소에 `render.yaml`을 넣어 두었습니다. Render가 이걸 읽어 자동으로 설정합니다.

1. https://dashboard.render.com/blueprints → **New Blueprint Instance**
2. GitHub 저장소 `parkganghyun123-sketch/KB` 선택 (첫 사용 시 GitHub 연결 승인)
3. Render가 `render.yaml`을 읽어 서비스 하나를 제안합니다 → **Apply**

빌드가 3~5분 걸립니다. Logs 탭에서 진행 상황을 볼 수 있습니다.

> Blueprint가 안 보이면 **New → Web Service**로 직접 만들어도 됩니다.
> Root Directory `TradeGuard` · Build `pip install -r requirements.txt`
> · Start `python3 -m uvicorn server.app:app --host 0.0.0.0 --port $PORT`

---

## 2. 환경변수 (배포 직후 바로)

Render 대시보드 → 서비스 선택 → **Environment**

| Key | Value | 비고 |
|---|---|---|
| `OPENAI_API_KEY` | 본인 키 | 또는 `ANTHROPIC_API_KEY` |
| `TG_UPLOAD_CODE` | 정한 접근 코드 | 없으면 판독이 무제한 개방됩니다 |

`render.yaml`에 이미 들어 있어 따로 넣지 않아도 되는 값입니다.

| Key | Value | 의미 |
|---|---|---|
| `TG_LIMIT_PER_IP` | `6` | 한 사람이 하루에 판독할 수 있는 장수 |
| `TG_LIMIT_TOTAL` | `60` | 전체 하루 총량 |

> 서류 1장당 AI 호출 2회, 3장 세트가 약 $0.06입니다.
> `TG_LIMIT_TOTAL=60`이면 **하루 최대 약 $0.6**입니다.

저장하면 자동으로 재배포됩니다.

## 3. 콜드스타트 대응 ★

**이게 이 배포의 유일한 실질적 위험입니다.** 15분간 아무도 안 들어오면 잠들고,
다음 사람이 **30~60초를 기다립니다.** 심사위원이 흰 화면을 보고 닫아버리면
배포한 의미가 없습니다.

두 가지를 같이 하십시오.

### ① 무료 핑 서비스로 깨워 두기 (권장)

https://uptimerobot.com 무료 가입 → **New Monitor**

| 항목 | 값 |
|---|---|
| Monitor Type | HTTP(s) |
| URL | `https://<서비스명>.onrender.com/api/health` |
| Monitoring Interval | **5 minutes** |

5분마다 `/api/health`를 두드려 계속 깨어 있게 합니다. 이 엔드포인트는
**LLM을 호출하지 않으므로 비용이 발생하지 않습니다.**

> 심사 기간(8/3 제출 ~ 8/20 발표)만 켜 두고 이후 끄면 됩니다.

### ② 안내 문구로 대비

핑을 걸어도 재배포 직후 등은 느릴 수 있습니다. 제출 자료에 한 줄 넣으십시오.

> 첫 접속 시 서버가 깨어나며 30초 정도 걸릴 수 있습니다.

## 6. 알아 둘 것

| 항목 | 내용 |
|---|---|
| **잠들기** | 15분 미사용 시. §3의 핑으로 대응합니다 |
| **감사 이력** | 재배포·재기동 시 사라집니다. 데모 목적에는 충분하고 **서류 내용은 애초에 기록하지 않습니다** |
| **환율** | ECOS 조회 실패 시 고정값으로 넘어갑니다. 화면에 `fallback`으로 표시되며 판정에는 영향이 없습니다 |
| **서류 이미지 생성** | 배포본에는 Playwright를 넣지 않았습니다(빌드 시간·용량 절약). 이미 만들어진 이미지 6장을 제공합니다 |
| **한도 초과 시** | 판독만 막히고 **샘플 모드는 계속 동작합니다** |
| **무료 플랜 한도** | 월 750시간. 서비스 1개면 상시 가동해도 넉넉합니다 |

## 7. 문제가 생기면

| 증상 | 조치 |
|---|---|
| Build failed | Logs 확인. `rootDir`이 `TradeGuard`인지, Python 3.11인지 확인 |
| `● 판독 엔진 미연결` | Environment에 키가 들어갔는지, 이름이 정확한지(`OPENAI_API_KEY`) 확인 후 **Manual Deploy → Deploy latest commit** |
| 접근 코드 칸이 안 보임 | `TG_UPLOAD_CODE` 미설정입니다. 설정 후 재배포 |
| 첫 접속이 너무 느림 | 잠든 상태입니다. §3의 핑을 설정하십시오 |
| 샘플이 안 나옴 | Logs에서 `/api/samples` 오류 확인. 케이스 JSON 누락 가능성 |

## 부록 — Dockerfile은 왜 남겨 두나

`Dockerfile`을 저장소에 함께 두었습니다. Render는 쓰지 않지만,

- 다른 환경(사내 서버·클라우드)에 올릴 때 그대로 쓸 수 있고
- 심사위원이 **"배포 가능한 형태로 만들어 뒀는가"**를 볼 때 근거가 됩니다

`docker build -t tradeguard . && docker run -p 7860:7860 tradeguard`로 로컬 확인이 가능합니다.
