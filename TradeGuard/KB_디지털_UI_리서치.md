## TradeGuard 적용 원칙

### 반드시 적용할 요소
1. 브랜드 색은 **CTA와 선택 상태에만** — 배경·장식에 쓰지 않음
2. **위험·주의 정보를 접히지 않게 상시 노출**
3. 푸터에 **면책·데이터 출처·프로토타입 고지** 밀집 배치
4. 스킵 링크 · 설명형 대체 텍스트 · 키보드 포커스 표시
5. 존댓말 · 확정적 단정 회피 ("~입니다" 대신 "~일 수 있습니다")

### 제한적으로 적용할 요소
- 메인/서브 컬러 체계 **개념**만 차용 (실제 값은 자체 정의)
- 업무 단위 메뉴 구조 → 우리는 단일 흐름이므로 단계 표시로 대체

### 적용하지 않을 요소
- Star-b 심볼 및 유사 형태 **일체 생성 금지**
- KB 로고·워드마크·캐릭터 이미지 사용 금지
- 로그인·계좌·인증 화면 모방 금지
- 이벤트·프로모션 시각 언어 금지

### 공식 서비스 오인 방지 (필수)
| 조치 | 구현 |
|---|---|
| 헤더에 출품작 배지 | `2026 KB AI Challenge 출품작` |
| 푸터에 명시적 고지 | "KB국민은행이 운영하는 서비스가 아닙니다" |
| 결과 화면 면책 | "참고용 사전 점검 결과이며 은행의 최종 심사 결과가 아닙니다" |
| 로고 | **TradeGuard 자체 워드마크만 사용** (KB 자산 미사용) |

## 디자인 토큰 초안

⚠️ **아래 값은 KB 공식 색상이 아니다.** 공식 HEX가 이미지로만 제공되어 확인할 수 없었으므로,
금융 UI 관례와 WCAG 대비 기준에 따라 **자체 정의**한 값이다.

| 토큰 | 값 | 용도 | 대비 검토 |
|---|---|---|---|
| `--primary` | `#FFBC00` | CTA 배경, 선택 상태 | 검정 텍스트와 조합 (11.4:1) |
| `--primary-ink` | `#26282C` | primary 위 텍스트 | — |
| `--neutral-900` | `#26282C` | 본문 텍스트 | 흰 배경 대비 14.2:1 |
| `--neutral-500` | `#5B6068` | 보조 텍스트 | 흰 배경 대비 6.4:1 (기존 #696E76에서 상향) |
| `--surface` | `#FFFFFF` | 카드 표면 | — |
| `--bg` | `#F6F7F8` | 페이지 배경 | — |
| `--border` | `#E4E6EA` | 경계선 | — |
| `--success` | `#067647` | 정상·완료 | 흰 배경 대비 5.3:1 |
| `--warning` | `#B54708` | 주의·확인 필요 | 흰 배경 대비 6.1:1 |
| `--danger` | `#C42B22` | 위험·오류 | 흰 배경 대비 5.9:1 (기존 #D92D20에서 상향) |
| `--info` | `#175CD3` | 안내·제안 | 흰 배경 대비 6.5:1 |

**브랜드 색과 상태 색을 분리한다** — 노랑은 상태를 뜻하지 않고 오직 행동 유도에만 쓴다.

## §7. 외부 검증이 필요한 항목

팀에서 브라우저로 직접 확인해야 하는 사항이다.

1. **KB 기업뱅킹 외환 화면의 실제 레이아웃** — 로그인 필요. 계좌 보유자가 확인 필요
2. **KB 공식 색상 HEX 값** — CI 페이지의 Color System 이미지를 육안 확인 필요
3. **브랜드 자산 사용 권한** — 대회 출품작이 KB 로고를 쓸 수 있는지 주최측 문의 필요
   → **확인 전까지 사용하지 않는다** (현재 방침)
4. **KB스타뱅킹 앱 화면** — 앱스토어 스크린샷 확인 필요

## §8. 프롬프트 인젝션 점검

조사한 3개 페이지에서 AI를 대상으로 한 지시문은 발견되지 않았다.
모든 페이지의 텍스트는 일반 안내·메뉴·브랜드 설명이었다.
