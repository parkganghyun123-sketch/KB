# TradeGuard 폐쇄 루프 성능 리포트

- 대상: 합성 벤치마크 40건 중 **하자 케이스 20건**
- 절차: 하자 검출 → 신용장 기준 수정 제안 → 제안 적용 → **재심사**
- LLM 호출 없음 (판정·제안 모두 결정적) → 비용 0원, 재현 가능

| 지표 | 값 |
|---|---|
| 재심사 통과율 (치유 가능 하자만 있는 16건 기준) | 100.0% |
| 치유 가능 하자 해소율 | 100.0% |
| 제안값 정확도 (신용장 기준값 일치) | 100.0% |
| 수정으로 인한 신규 하자 | 0건 |
| 재심사 처리시간 (평균 / 최대) | 0.1ms / 0.1ms |

## 치유 불가 하자를 포함한 케이스 — 4건

서류 수정으로 치유되지 않는 하자(선적기일 경과·제시기한 경과)가 있는 케이스는
**의도적으로 A등급에 도달시키지 않는다.** 자동으로 '해결됨'이라 표시하는 대신
개설의뢰인 waiver 또는 신용장 조건변경이 필요하다고 남긴다.

| 케이스 | 등급 | 치유 불가 하자 |
|---|---|---|
| DEFECT-009 | C→C | LATE_SHIPMENT |
| DEFECT-010 | C→C | LATE_SHIPMENT |
| DEFECT-011 | C→C | LC_EXPIRED_OR_LATE_PRESENTATION |
| DEFECT-012 | C→C | LC_EXPIRED_OR_LATE_PRESENTATION |

> 재심사 통과율은 치유 가능 하자만 있는 케이스를 분모로 한다.
> 치유 불가 하자가 있는 케이스를 분모에 넣으면 '고칠 수 없는 것을 못 고쳤다'는
> 이유로 성능이 낮게 보이지만, 그건 성능이 아니라 정의의 문제다.
